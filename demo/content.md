# UnderFlow

A markdown editor with a live preview and a WYSIWYG mode. It reads and writes **CommonMark** and _GitHub Flavored Markdown_.

## Lists

-   [x] Task lists
-   [ ] Nested lists
    1.  ordered
    2.  items

> Block quotes, `inline code` and [links](https://github.com/Liquid-JS/underflow).

| Syntax            | Supported |
| ----------------- | :-------: |
| Tables            |    yes    |
| ~~Strikethrough~~ |    yes    |

```js
const editor = new Editor({ el, initialValue: '# Hello' });
```
